# Trabajo Práctico 1 y 2: Sistema de Desplazamiento de LEDs y Generador PRBS

En este trabajo práctico, una vez estudiada la parte teórica introductoria de diseño RTL en Verilog, se pasó al desarrollo de código necesario para la implementación un sistema de shifteo de leds, para poder ser cargado en una FPGA Artix-7 XC7A100T tanto del diseño sintetizable como los tests correspondientes. 

En esta carpeta se encuentra adjunto el informe en formato PDF detallando el trabajo. [Informe Trabajos practicos 1 y 2 - Protocolos 2026 - Facundo Guerrero.pdf](./Informe%20Trabajos%20practicos%201%20y%202%20-%20Protocolos%202026%20-%20Facundo%20Guerrero.pdf)
