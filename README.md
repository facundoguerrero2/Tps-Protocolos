# Repositorio de Trabajos y Laboratorios

Este repositorio contiene todo el trabajo realizado en el curso Protocolos de Comunicaciones de Alta Velocidad, de la Fundación Fulgor desde el 7/5/26 hasta el 31/10/26. El material está organizado en carpetas correspondientes a los distintos trabajos prácticos (TPs) y laboratorios. 

Dentro de cada carpeta se encuentran los informes correspondientes y un archivo `README.md` propio con los enlaces a los repositorios externos donde se trabajó el código fuente.

## Estructura de Carpetas

* **[Tp1y2](./Tp1y2):** Diseño y testeo de un sistema de desplazamiento de LEDs con implementación en FPGA Artix-7 XC7A100T y de un generador PRBS para detección de errores en comunicación.
* **[EthernetLabs](./EthernetLabs):** Distintos laboratorios y experiencias de ejecución donde se analizaron las tramas y se observó el comportamiento de las distintas subcapas del protocolo ethernet (XGMII, PCS, etc.).
* **[T_Axi](./T_Axi):** Se trabajo en testeo y verificación del módulo top `taxi_eth_phy_10g`.
